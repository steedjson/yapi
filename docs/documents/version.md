# 版本说明（v2.0.0）

v2.0.0 是一次以现代化地基为主的大版本升级，涉及运行环境、前端技术栈与安全基线，升级前请先阅读以下变更说明。

## 运行环境要求

- Node.js >= 22.12（见 package.json engines）
- MongoDB（mongoose 8 驱动）

## 客户端技术栈现代化

- 组件库升级至 antd v6，React 19，react-router v7
- 生产构建由 webpack 迁移至 rsbuild（产物输出至 static/prd）

## 编辑器引擎迁移

- 接口编辑、接口预览、Mock 脚本与测试脚本编辑器由 Ace 迁移至 CodeMirror 6

## 安全基线升级

- 密码散列算法升级为 scrypt；存量 sha1 口令在用户登录时自动升级，无需人工迁移
- 开放接口（openapi）token 语义明确为「归属项目内的开发者」：
  - 数据面读写（15 个端点）均可用，私有项目同样可调用
  - 项目配置修改（/api/project/up）与删除类操作不支持 token 调用
  - 包装串（设置页展示串）绑定查看者身份，不继承其全局角色
  - 被禁用或已删除账号的包装串立即失效

## 接口与文档

- 接口导出：/api/plugin/exportSwagger 需携带参数 type=OpenAPIV2
- 页脚「使用文档」改为站内展示，文档随部署一起提供，不再依赖外部站点

## UI 规范修复批

- 接口树收起意图保持、编辑器容器高度、弹窗按钮对齐等一批交互细节修复

详细变更见仓库 docs/BUGLOG/ 与 git 提交史。
